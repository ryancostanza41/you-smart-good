What is binary?

You know that image of the 0s and 1s that you probably associate with the Matrix movies?
Well, that's binary.
But what is it? and how do you use it?

Binary code is the most basic language of computers.
It is the foundation of all digital electronics.
Binary code is built on a base-2 number system, as it only uses two symbols: 0 and 1.

Think of it like this:
At its absolute basic building block, a computer is a combination of transistors.
A transistor can only be one of two things: Off (0) and On (1).
Hence, binary code!

Each individual digit in a Base-2 numbering system is referred to as a "Bit."

A combination of four bits is one nibble.

And a combination of eight bits is one byte!
