As you've probably noticed, storage is extremely important in programming.
I mean, if you're working with a byte and you want to write out the number 1, it's 0 0 0 0 0 0 0 1.
That's a lot of work just to write the number 1!
Not only is it a lot of work, but it's also very limiting. Each column can only either be 0 or 1. As far as integers go, there isn't much that you can fit in Base-2.
What if there was a way to hold more numbers? We know we're familiar with Base-10 (0-9), but what if there was a larger system that we could use? Something that could hold more data in less storage . . .
